Event Management Application

The Event Management Application is a web-based platform developed using Flask, Python, HTML, CSS, JavaScript, and MySQL.
It is designed to make managing and participating in events simple and organized.
Users can create an account, sign in, view available and upcoming events, and register for events.
The application also provides user profile management and an organized interface for browsing event information.
The system uses MySQL to securely store user, event, and event-registration data, while Flask handles the backend logic and communication between the website and database.
Overall, the application provides a convenient platform for event discovery, user management, and event registration in one place.
