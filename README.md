# Event Management Application

A web-based Event Management Application developed using **Python, Flask, MySQL, HTML, CSS, and JavaScript**.

## Features

* User registration and sign-in
* Browse available and upcoming events
* Event registration
* User profile management
* Event information and details
* MySQL database integration
* Responsive and user-friendly interface

## Technologies Used

* Frontend: HTML, CSS, JavaScript
* Backend: Python, Flask
* Database: MySQL
* Development Environment: Visual Studio Code

## Project Description

The application provides a centralized platform where users can create an account, sign in, explore events, and register for events. Flask handles the backend functionality, while MySQL stores user, event, and registration information.

## How to Run

1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install the required packages.
4. Configure the MySQL database.
5. Run the Flask application.
